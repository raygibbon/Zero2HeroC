# Module 0: Before You Can Program

**Begin here.** This module assumes you have never programmed in C and might never have used a compiler or a terminal. It is deliberately slower than a typical “C in one hour” tutorial.

**Goal:** By the end, you will know what source code and a compiler are, be able to navigate to a folder, write a small C program, compile and run it, and find a simple error. You will *not* need SDL3, pointers, variables or game engines yet.

## Learning method

Read a chapter, carry out its activity, compare the result, then complete the checkpoint before continuing. Type examples manually. If something fails, save the exact error message in your practice notes.

### Where you are heading

You will finish by printing a tiny retro game title screen in the terminal. This is intentional: we will learn C carefully before introducing SDL3 windows, textures and input.

### Important distinctions

- A **text editor** is for writing source code.
- A **compiler** translates C into a runnable program.
- A **terminal** is one way to invoke the compiler and run that program.
- **SDL3** is a library we will use later; it is not required for Module 0.
