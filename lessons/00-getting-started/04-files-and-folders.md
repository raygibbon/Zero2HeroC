# 0.04 Files, folders and extensions

[← Module 0 contents](README.md)

**Goal:** Keep source files in predictable places before learning compiler commands.

## Your practice workspace

Create the following folders using your file manager:

```text
zero2heroc-practice/
└── module-00/
    └── hello/
```

A **folder** (also called a directory) holds files and other folders. A **path** identifies where something is stored. For example `module-00/hello/hello.c` is a relative path from inside `zero2heroc-practice`.

Different operating systems use slightly different separators: Windows commonly uses `\` in paths, while Linux and macOS use `/`. Use the path format shown in your terminal.

## Watch the extension

Windows may hide known extensions. Make sure `hello.c` is not accidentally named `hello.c.txt`. If you use Windows File Explorer, enable **View → Show → File name extensions**.

## Activity

Inside `hello`, create `readme.txt` containing the sentence: `I will put my first C program in this folder.` Close and reopen it.

## Check yourself

- What is the difference between a folder and a file?
- Which folder will hold `hello.c`?
- Why can hidden file extensions be confusing?
