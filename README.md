# Zero2HeroC

**Learn C from absolute zero. Build games with SDL3. Eventually understand how a small game engine works.**

No prior programming knowledge is required. This is a hands-on, old-school programming course: type every example, run it, experiment with it, and understand *why* it works.

## Start here

**[Module 0: Before You Can Program](lessons/00-getting-started/README.md)**

Module 0 begins before C syntax: programs, source files, terminals, compilers, setting up tools and writing the first tiny C program. Each numbered lesson is a separate Markdown chapter and contains a small activity, an expected result, a troubleshooting note and links back to earlier lessons used.

## How to study

1. Read lessons in order. Do not skip because the topic sounds familiar.
2. Type the examples yourself rather than pasting them.
3. Compare actual output with the expected output.
4. Try the exercise before reading the answer or continuing.
5. Use **Previous lessons used** at the bottom of each lesson to revisit forgotten techniques.

**Tooling:** Use a terminal, a text editor, and a C compiler (GCC or Clang). SDL3 is deliberately *not* required in Module 0. We will introduce it only after building a foundation in C.

## Course direction

1. Understand the tools and your first C program.
2. Learn the C language in small, carefully explained steps.
3. Build text-based games to practise game logic.
4. Learn SDL3: windows, input, drawing, timing, textures and audio.
5. Complete small 2D games.
6. Learn game architecture, performance and simple raycasting.
7. Build a small, purpose-built framework.

The course will grow lesson by lesson. Unwritten modules are **plans, not completed tutorials**.
